# ระบบจดและติดตามค่าน้ำ - ค่าไฟ บ้านพักครู (สามสาระ)

Web App แบบ Mobile-First สำหรับดูยอดบิล แนบสลิปโอนเงิน ติดตามสถิติย้อนหลัง และบริหารจัดการจดมิเตอร์บ้านพักครู (สามสาระ) โดยใช้ **Google Sheets + Google Drive + Google Apps Script (GAS)** เป็น Backend ฟรีทั้งหมดและเก็บหลักฐานได้ถาวร

---

## ความสามารถหลักของระบบ

### ฝั่งครูผู้พักอาศัย (ไม่ต้องล็อกอิน)
- ดูยอดค่าน้ำและค่าไฟประจำเดือน พร้อมเลือกดูประวัติย้อนหลังได้ทุกเดือนและทุกปี พ.ศ.
- ดูรายละเอียดการคำนวณของแต่ละห้อง (เลขอ่านก่อน, เลขอ่านหลัง, หน่วยที่ใช้, ค่าน้ำ, ค่าไฟ, รวม)
- คัดลอกเลขบัญชีโอนเงินได้ใน 1 คลิก
- อัปโหลดรูปสลิปแจ้งโอนเงิน (บีบอัดรูปภาพอัตโนมัติก่อนส่ง เพื่อความรวดเร็วบนมือถือ) และเปิดดูหลักฐานสลิปย้อนหลังได้ตลอดกาล
- ดูกราฟแนวโน้มค่าไฟทั้งบ้านพัก กราฟการใช้ไฟรายบุคคล (รวมถึงครูที่ย้ายออกไปแล้ว) และ Export ข้อมูลรายปีเป็นไฟล์ CSV (เปิดใน Excel ภาษาไทยไม่เพี้ยน)

### ฝั่งผู้ดูแล / ผู้จดมิเตอร์ (ล็อกอินด้วย PIN)
- **จดมิเตอร์เร็ว (Quick Meter Entry):** เดินกรอกเลขมิเตอร์ผ่านมือถือ คำนวณยอดแบบ Real-time พร้อมแจ้งเตือนทันทีหากเลขใหม่น้อยกว่าเลขเดิม
- **ตรวจสลิปและสถานะการจ่าย:** แยกรายการรอตรวจไว้ด้านบน เปิดดูรูปสลิปเต็มจอ อนุมัติ ตีกลับพร้อมเหตุผล หรือบันทึกชำระเงินสดได้ทันที
- **จัดการครูเข้า-ออก:** เพิ่มครูย้ายเข้าพร้อมระบุเลขมิเตอร์เริ่มต้น และแจ้งย้ายออกโดยไม่ลบข้อมูลเก่า (ประวัติบิลเดือนก่อนไม่เปลี่ยนแปลง)
- **รอบบิล รายงาน และตั้งค่า:** ขึ้นรอบบิลเดือนใหม่โดยดึงเลขมิเตอร์ล่าสุดมาให้อัตโนมัติ, ปิด/เปิดรอบบิล, คัดลอกข้อความสรุปส่ง LINE, สั่งพิมพ์ตารางส่งโรงเรียนขนาด A4, แก้ไขข้อมูลบัญชีธนาคาร และเปลี่ยนรหัส Admin PIN

## ขั้นตอนการติดตั้งใช้งานจริง (Step-by-Step)

### ขั้นที่ 1: สร้าง Google Sheets เปล่า
1. ไปที่ [Google Sheets](https://sheets.google.com) แล้วสร้างไฟล์สเปรดชีตใหม่
2. ตั้งชื่อไฟล์ เช่น **`ฐานข้อมูลค่าน้ำค่าไฟ บ้านพักครูสามสาระ`**

### ขั้นที่ 2: ติดตั้งสคริปต์ Google Apps Script (Backend)
1. ในหน้า Google Sheets ที่สร้างไว้ คลิกเมนูด้านบน **ส่วนขยาย (Extensions) → Apps Script**
2. ตั้งชื่อโปรเจกต์ Apps Script เช่น **`Samsara Utility API`**
3. ในไฟล์ `Code.gs` เดิม ให้ลบโค้ดทั้งหมด แล้วคัดลอกเนื้อหาจากไฟล์ [`gas-backend/Code.gs`](gas-backend/Code.gs) มาวาง
4. กดปุ่ม **`+`** ข้างหัวข้อ **ไฟล์ (Files)** → เลือก **สคริปต์ (Script)** → ตั้งชื่อว่า **`setup`** (จะได้ไฟล์ `setup.gs`)
5. คัดลอกเนื้อหาจากไฟล์ [`gas-backend/setup.gs`](gas-backend/setup.gs) มาวางใน `setup.gs` แล้วกด **บันทึก (Ctrl + S)**

### ขั้นที่ 3: สร้างฐานข้อมูลและข้อมูลตั้งต้น (รันครั้งเดียว)
1. เปิดไฟล์ `setup.gs` ในหน้า Apps Script
2. ตรงแถบเครื่องมือด้านบน เลือกฟังก์ชัน **`setupDatabase`** แล้วกดปุ่ม **เรียกใช้ (Run)**
3. ระบบจะขออนุญาตสิทธิ์เข้าถึง Google Sheets และ Google Drive:
   - กด **ตรวจสอบสิทธิ์ (Review permissions)** → เลือกบัญชี Google ของคุณ
   - หากขึ้นหน้าแจ้งเตือน *"Google hasn't verified this app"* ให้กด **ขั้นสูง (Advanced)** → **ไปที่ Samsara Utility API (ไม่ปลอดภัย)** → **อนุญาต (Allow)**
4. รอจนเสร็จและดูที่ Execution log ระบบจะสร้าง:
   - 5 แท็บในชีต: `Settings`, `Residents`, `Billing_Cycles`, `Meter_Records`, `Audit_Logs`
   - โฟลเดอร์ `Samsara-Utility-Slips` ใน Google Drive พร้อมบันทึก `slip_folder_id` ลงในแท็บ `Settings`
   - รหัส `ADMIN_PIN` เริ่มต้นใน Script Properties คือ **`1234`** (สามารถเปลี่ยนได้ภายหลังผ่านหน้าตั้งค่าในเว็บ หรือรันฟังก์ชัน `setAdminPin()` ใน `setup.gs`)
   - ข้อมูลตั้งต้นรอบบิลเดือนพฤศจิกายน 2569 (`2026-11`) ทั้ง 9 ห้อง (ยอดรวมสุทธิ 3,083 บาท)

### ขั้นที่ 4: Deploy Google Apps Script เป็น Web App
1. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** มุมขวาบน → เลือก **การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดไอคอนฟันเฟืองตรง *เลือกประเภท* → เลือก **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย:** `v1.0 Initial Release`
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)`
4. กด **ทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL ของเว็บแอป (Web app URL)** ที่ลงท้ายด้วย `/exec` เก็บไว้

> **หมายเหตุสำคัญเมื่อแก้ไขโค้ด GAS ในอนาคต:** ทุกครั้งที่แก้โค้ดใน `Code.gs` ต้องกด **Deploy → จัดการการทำให้ใช้งานได้ (Manage deployments) → แก้ไข (ไอคอนดินสอ) → เวอร์ชันใหม่ (New version) → ทำให้ใช้งานได้** URL เดิมจะยังคงใช้ได้ต่อเนื่อง

### ขั้นที่ 5: เชื่อมต่อ URL กับ Frontend (`web/js/config.js`)
1. เปิดไฟล์ [`web/js/config.js`](web/js/config.js)
2. นำ Web App URL ที่ได้จากขั้นที่ 4 มาใส่ในค่า `GAS_WEB_APP_URL`:
   ```js
   const CONFIG = {
     GAS_WEB_APP_URL: 'https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec',
     // ...
   };
   ```
3. บันทึกไฟล์ (หากปล่อยค่าว่างไว้ เว็บจะเปิดใน **โหมดข้อมูลจำลอง (Mock Mode)** อัตโนมัติเพื่อให้พรีวิวและทดสอบได้ทันที)

### ขั้นที่ 6: นำหน้าเว็บขึ้นใช้งานออนไลน์

#### วิธีที่ 1: Deploy บน GitHub Pages (ฟรี)
1. Push โปรเจกต์ขึ้น GitHub Repository ของคุณ
2. เข้าหน้า Repository → **Settings → Pages**
3. ในหัวข้อ **Build and deployment** เลือก Source เป็น **Deploy from a branch** → เลือกสาขา **`main`** และโฟลเดอร์ **`/(root)`** → กด **Save**
4. เมื่อเผยแพร่แล้ว จะได้ลิงก์ `https://<username>.github.io/samsara-utility-bill/` นำไปแชร์ในกลุ่ม LINE บ้านพักครูได้ทันที

#### วิธีที่ 2: Deploy บน Vercel (ฟรีและเร็วที่สุด)
1. เข้า [vercel.com](https://vercel.com) → **Add New Project** → เชื่อมต่อ GitHub Repository `samsara-utility-bill`
2. ปล่อย **Root Directory**, **Build Command** และ **Output Directory** เป็นค่าเริ่มต้น (Static HTML) แล้วกด **Deploy**
3. นำ URL ที่ได้ไปใช้งานและเปิดในมือถือได้ทันที

## การติดตั้งเป็นเว็บแอปบนมือถือและคอมพิวเตอร์ (PWA)

ระบบรองรับการติดตั้งเป็นเว็บแอป (Progressive Web App) พร้อมไอคอนเฉพาะบนหน้าจอหลัก เพื่อให้ครูเปิดดูบิลและส่งสลิปได้ทันทีโดยไม่ต้องเปิดลิงก์ใหม่ทุกเดือน:

- **Android (Chrome / Edge / Samsung Internet):** เปิดลิงก์เว็บแล้วกดปุ่ม **ติดตั้งแอป** บนแถบด้านบน หรือบนแบนเนอร์แนะนำ เพื่อยืนยันติดตั้งได้ทันที
- **iPhone / iPad (Safari):** กดปุ่ม **ติดตั้งแอป** เพื่อดูขั้นตอน หรือแตะปุ่ม **แชร์ (Share) → เพิ่มไปยังหน้าจอโฮม (Add to Home Screen) → เพิ่ม**
- **กรณีเปิดลิงก์จากกลุ่ม LINE:** แตะเมนูมุมขวาล่าง/ขวาบนแล้วเลือก **เปิดด้วยเบราว์เซอร์เริ่มต้น (Chrome / Safari)** ก่อน จึงจะสามารถกดติดตั้งไอคอนลงหน้าจอหลักได้
- **คอมพิวเตอร์ (Chrome / Edge):** กดปุ่ม **ติดตั้งแอป** บนแถบด้านบน หรือคลิกไอคอนติดตั้งในแถบ Address Bar

## การทดสอบบนเครื่องคอมพิวเตอร์ (Local Preview)

สามารถดับเบิลคลิกเปิดไฟล์ [`index.html`](index.html) ในเบราว์เซอร์ได้โดยตรง หรือเปิดผ่าน Local HTTP Server:

```bash
npx serve .
```
หรือด้วย Python:
```bash
python -m http.server 8080
```
จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:8080` (หรือพอร์ตที่คำสั่งแสดง)
- **รหัส Admin PIN เริ่มต้น:** `1234` (แนะนำให้เปลี่ยนทันทีเมื่อนำขึ้นใช้งานจริงผ่านเมนู **ผู้ดูแลระบบ → รอบบิล & ตั้งค่า**)

## คำแนะนำด้านความปลอดภัยและการดูแลรักษา

1. **เปลี่ยนรหัส PIN ทันทีหลังติดตั้ง:** เข้าแท็บผู้ดูแลระบบด้วย PIN `1234` แล้วเปลี่ยนเป็นรหัส 4–6 หลักเฉพาะผู้ดูแล
2. **ห้ามลบแถวในแท็บ `Residents`:** หากครูย้ายออกให้ใช้ปุ่ม *แจ้งย้ายออก* ในระบบเท่านั้น เพื่อรักษาความเชื่อมโยงของประวัติบิลและกราฟย้อนหลัง
3. **การสำรองข้อมูล:** สามารถดาวน์โหลดไฟล์ Google Sheets หรือกดปุ่ม Export CSV รายปีจากหน้า *สถิติ & ย้อนหลัง* เก็บไว้เป็นหลักฐานประจำปีได้ตลอดเวลา
